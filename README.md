# DataScientist
En este repositorio se almacenara script de usos diarios para facilitar la toma de datos y transformacion
- Contador de Ficheros con actualizacion de tiempos
- Lector de log de FTPS, te muestran los errores que puede presentarse durante el dia
- Extracion de facturas en SAP, registros grandes
- Concatenacion de registros
